Integração MCP Model Context Protocol

Conecte o GerminaVision à sua IA favorita (Claude, Cursor, Cline) para que ela possa visualizar e analisar suas mudas automaticamente.

1. Configuração no Claude Desktop

No Mac:

Abra o arquivo de configuração localizado em:

~/Library/Application Support/Claude/claude_desktop_config.json
No Windows:

Abra o arquivo de configuração localizado em:

%APPDATA%\Claude\claude_desktop_config.json
Adicione o servidor:

Cole o seguinte código JSON, substituindo /caminho/absoluto/projetogerminação pelo caminho real da pasta do projeto na sua máquina:

{
  "mcpServers": {
    "germinavision": {
      "command": "python",
      "args": [
        "/caminho/absoluto/projetogerminação/mcp_server.py"
      ]
    }
  }
}

Após salvar, reinicie o Claude Desktop. O ícone 🔌 (plugue) aparecerá indicando que as ferramentas foram carregadas.

2. Configuração no Cursor IDE

O Cursor tem suporte nativo para MCP. Para adicionar o GerminaVision:

  1. Abra as configurações do Cursor (Cmd + Shift + J ou vá em Cursor Settings > Features > MCP).
  2. Clique em + Add New MCP Server.
  3. Tipo: command
  4. Comando: python /caminho/absoluto/projetogerminação/mcp_server.py

Ferramentas Disponíveis para a IA

Uma vez integrado, a IA poderá usar as seguintes ferramentas autonomamente para responder suas dúvidas e analisar fotos:

🔍 analyze_image

A IA pode rodar o modelo YOLO11 em uma nova foto e salvar o resultado anotado, retornando as estatísticas na hora.

📈 get_temporal

Retorna toda a evolução temporal da sua plantação agregada por dias (D0, D1, D2).

🗂 get_history

Lê as últimas análises do banco de dados (histórico bruto).

📊 get_stats

Puxa o resumo geral (taxa média, número total de mudas detectadas, folhas).

💬 ask

Chama o GerminaBot nativamente para consultar regras internas ou dicas de plantio.

🟢 status

Verifica a saúde do servidor MCP, caminho do modelo e do banco de dados.
